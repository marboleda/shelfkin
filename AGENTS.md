# Shelfkin

Shelfkin is an app for managing a household pantry. It has an Expo / React Native front-end and Go backend.

## Repository layout

- `app/` contains the Expo and React Native front-end code.
- `api/` contains the Go backend code.

## Orchestration

Reference `docs/process.md` to see how work is organized and how features should be implemented
